# Gmail Automation

This project demonstrates an automated email workflow using n8n and Gmail.

## Workflow

Manual Trigger → Gmail → Send Email

## Technologies Used

- n8n
- Gmail API
- Google Cloud
- Docker

## Description

This n8n workflow is designed to send an email automatically through Gmail.

The workflow uses a Manual Trigger to start the process and a Gmail node to send the email.

## How It Works

1. Start the workflow using the Manual Trigger.
2. The Gmail node connects to the configured Gmail account.
3. Enter the recipient email address.
4. Enter the email subject and message.
5. Execute the workflow.
6. The email is sent through Gmail.
